# StackForge - Producto 3

Plataforma de intercambio de idiomas.

Proyecto de Desarrollo Full Stack con JavaScript - UOC.

En este producto se desarrolla el backend de la aplicación mediante Node.js, ExpressJS y GraphQL, utilizando MongoDB Atlas para almacenar los datos de usuarios, intercambios y selecciones.

Las funcionalidades se implementan mediante consultas y mutaciones GraphQL y se comprueban con Postman.
